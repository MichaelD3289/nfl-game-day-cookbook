Prepared 2026-11-15. Six recipes had searches that earlier rate limits and server errors cut short. These searches were run again, alternating between Wikimedia Commons and Openverse. Each license and author below was read from the Commons API or the Flickr photo page, and each photo was checked by eye against its recipe before use.
