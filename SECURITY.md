# Security

Use GitHub's private [Report a vulnerability](https://github.com/MichaelD3289/nfl-game-day-cookbook/security/advisories/new)
form for leaked credentials, unsafe build behavior, or other security issues. Include
reproduction details and affected versions, but never post active secrets publicly.
The maintainer reviews reports as availability allows; no response-time guarantee is made.

Security fixes target current `main` and the latest release. Routine recipe corrections
belong in issues. For urgent food-safety concerns, clearly flag the recipe and concern.
